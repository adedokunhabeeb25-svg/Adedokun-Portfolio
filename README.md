# Adedokun Habeeb — Static HTML Portfolio

This is a plain HTML/CSS/JavaScript version of the portfolio.

## Deploy to Netlify

No Node.js, React, TypeScript or build command is required.

1. Upload this folder to a GitHub repository, keeping `index.html`, `styles.css`, `script.js` and `assets/` at the repository root.
2. In Netlify, import the GitHub repository.
3. Build command: leave blank.
4. Publish directory: `/` (root).
5. Deploy.

You can also drag the entire folder into Netlify Drop.
